An AI-powered Disaster Response & Emergency Management Platform built to assist authorities, rescue teams, and emergency responders in monitoring disasters, managing resources, and coordinating rescue operations in real time.

---

## 🚀 Overview

The AI Disaster Response Platform provides a centralized dashboard that enables emergency management teams to:

- Monitor live disaster incidents
- Track rescue teams
- Manage hospitals and relief camps
- Handle SOS requests
- View analytics and reports
- Make faster, data-driven decisions using AI

The platform aims to improve disaster response efficiency by providing real-time information through a clean and interactive dashboard.

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/sanviashish/ai-disaster-response-platform.git
```

---

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Runs on:

```
http://localhost:3000
```

---

### Backend

```bash
cd backend

python -m pip install -r requirements.txt

python -m uvicorn main:app --reload
```

Runs on:

```
http://127.0.0.1:8000
```

API Documentation:

```
http://127.0.0.1:8000/docs
```
